# OpenHack-2.7

Port of [OpenHack](https://github.com/Prevter/GDOpenHack) (MIT) to Geometry Dash 2.2081, Geode SDK 5.11.2, Android.

Tap the round **OH** button (drag to move it) to open the menu.

Features: Speedhack, Safe Mode, Freeze Jumps/Attempts, Music Unlocker, Unlock All, Noclip (+per player, +death limit),
Show Hitboxes, Respawn Delay, Auto Kill, No Camera Shake/Zoom, Accurate Percentage, RGB Icons, No Death Effect,
No Respawn Flash, No Particles, Solid / No Wave Trail, Text Bypass, Character Filter.

Build: push to GitHub, run the "Build OpenHack-2.7" workflow, download the `OpenHack-2.7` artifact (`.geode`).
